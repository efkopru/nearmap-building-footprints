# Figure provenance and reproduction

Both PNGs are original documentation illustrations, generated by [render_readme_figures.py](../../scripts/render_readme_figures.py). They contain no downloaded images, Nearmap imagery, private records, trained model output, or performance measurements.

- `workflow.png` describes the implemented local workflow and optional fine-tuning route. Guided modes require human input. Imported vectors are provider output, not locally run inference.
- `synthetic-example.png` uses deterministic, invented streets, trees, and 12 roof geometries. The reference overlay is made from the exact shapes that draw the raster, including a courtyard hole. It is **not independent ground truth or model output**. The stated scale is illustrative.

The generator uses NumPy and Pillow, with no GIS, ArcGIS, or model dependencies. Install these into a separate documentation environment if they are unavailable:

```bash
python -m pip install numpy Pillow
python scripts/render_readme_figures.py
```

The output directory defaults to `docs/images`. The script replaces only `workflow.png`, `synthetic-example.png`, and `provenance.json` there. An alternative directory can be supplied with `--output-dir`.

Font discovery uses Arial on Windows/macOS or DejaVu Sans on Linux. To reproduce identical typography, provide the same font files explicitly:

```bash
python scripts/render_readme_figures.py --font-regular /path/to/regular.ttf --font-bold /path/to/bold.ttf
```

`provenance.json` records the random seed, library versions, font hashes, generator hash, output dimensions, and image hashes. Byte-identical rendering requires the same font files and rendering-library versions; geometry and the synthetic noise seed are fixed in the source. Font files are not redistributed in this repository. The figures were rendered and visually inspected before inclusion.
